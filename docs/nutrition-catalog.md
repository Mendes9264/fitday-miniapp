# 500 道中餐目录的估算方法

本目录用于个人饮食记录，不是菜品检测报告。每道菜给出一份示例配方：各食材、调味料和烹调油合计为 **100 克可食用成品**，按各食材每百克的热量、蛋白质、碳水化合物和脂肪加权计算。结果中的热量取整数，三大营养素保留一位小数。加入一餐后，按实际克数线性换算；单餐的热量范围按目录估算值上下浮动 35%。

基础食材值主要参考 [USDA FoodData Central](https://fdc.nal.usda.gov/download-datasets/) 的公开食物成分资料；网页目录里的配方比例、用油和名称匹配是本项目为预览版编写的假设，**不能声称 500 道菜均有对应的网上实测值**。对没有可靠单独数据的食材（如海肠、土笋、驴肉、乳扇），目录会在食材名称中标出所用的近似值。香港食物安全中心的[中式点心研究](https://www.cfs.gov.hk/english/programme/programme_rafs/programme_rafs_n_01_03_ra_dim_sum.html)也说明，复合菜肴会因配方和烹调方法产生较大差异；本项目没有复制其受限制的逐项研究数据。

地方菜名称与主要食材参考公开介绍，例如[烟台市政府的海肠捞饭介绍](https://www.yantai.gov.cn/col/col11771/art/2026/art_7a0649fbcdc14a5fa4d423ba5cc1e6d8.html)、[临沂市文旅局的临沂炒鸡介绍](https://wgxj.linyi.gov.cn/info/1517/67777.htm)，以及[毛血旺配方示例](https://www.wangjiadu.net/products_details/62.html)。这些来源用于核对菜名和构成，**并未提供本目录的热量数值**。

数据定义在 [`web/dish-catalog.js`](../web/dish-catalog.js)。每行是“菜名｜类别｜示例配方”，可按实际家常做法继续修订。高油菜、带汤菜和带骨菜的偏差通常更大；目前目录里的鱼、虾、排骨等按可食用部分估算，称重时请尽量填写吃下的净重。
