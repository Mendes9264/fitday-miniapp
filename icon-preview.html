🎨 设计说明

  • 哑铃图标（左侧）：代表力量训练，每周四次健身房锻炼
  • 碗与筷子（右侧）：代表中餐饮食追踪和营养估算
  • 加号连接：象征"练"与"食"的结合，体现app核心理念
  • 绿色渐变背景：健康、活力、自然的色调
  • 橙色点缀：食物、能量、热情的视觉元素
  • 底部"练食"文字：清晰的app名称标识

📱 需要的图标尺寸

Android 应用

需要将 SVG 转换为以下 PNG 尺寸，放置在相应目录：

  • mipmap-mdpi/ic_launcher.png - 48x48
  • mipmap-hdpi/ic_launcher.png - 72x72
  • mipmap-xhdpi/ic_launcher.png - 96x96
  • mipmap-xxhdpi/ic_launcher.png - 144x144
  • mipmap-xxxhdpi/ic_launcher.png - 192x192

Web 应用

  • favicon.ico - 16x16, 32x32, 48x48 (多尺寸ICO)
  • icon-192.png - 192x192 (PWA)
  • icon-512.png - 512x512 (PWA)
  • apple-touch-icon.png - 180x180 (iOS)

转换命令（需要安装工具）

方法1：使用在线工具

访问以下网站上传 app-icon.svg：

  • CloudConvert
  • Convertio
  • Aconvert

方法2：使用 ImageMagick（命令行）

# 安装 ImageMagick for Windows
# 下载: https://imagemagick.org/script/download.php#windows

# 生成各种尺寸
magick app-icon.svg -resize 48x48 icon-48.png
magick app-icon.svg -resize 72x72 icon-72.png
magick app-icon.svg -resize 96x96 icon-96.png
magick app-icon.svg -resize 144x144 icon-144.png
magick app-icon.svg -resize 192x192 icon-192.png
magick app-icon.svg -resize 512x512 icon-512.png

方法3：使用 Inkscape（免费图形软件）

# 下载安装 Inkscape: https://inkscape.org/zh-hans/

# 打开 app-icon.svg
# 文件 → 导出PNG图像
# 设置所需尺寸后导出

🔄 备用设计建议

如果您想要不同的风格，可以考虑：

  • 极简版：只保留哑铃和碗的剪影，去掉文字
  • 圆形版：将所有元素放入圆形边框内
  • 单色版：使用纯色背景，白色图标元素
  • 渐变优化：调整颜色方案以适配不同主题
